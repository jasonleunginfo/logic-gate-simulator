# Logic Gate Simulator

A lightweight Python script designed to simulate fundamental logic gates. This project demonstrates proficiency in Python control flow, logical operators, and clean code practices.

## Features
- Supports **AND, OR, NOT, and XOR** operations.
- Includes **Type Hinting** for better code readability.
- Basic error handling for unsupported gate types.

## Usage
Run the script directly using Python:
`python logic_gate.py`

## Why I Built This
As a Artificial Intelligence and Philosophy student, I wanted to bridge the gap between formal logic and practical software development. This tool serves as a foundational project for my transition into technical roles.
